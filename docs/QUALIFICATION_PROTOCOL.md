# Qualification Protocol

The binding scientific question is:

> Does changing this internal state predictably change what the same individual attends to, remembers, predicts, learns, decides, or does later, while preserving historical truth and architectural authority?

Every behavioral donor experiment must freeze a champion, create matched forks, identify the exact internal intervention, declare the target downstream channel before examining results, use deterministic replicates where useful, preserve host-owned truth, preserve authority boundaries, test persistence when the claim is longitudinal, and perform a donor-removal ablation.

A donor that affects only generated wording is not a cognitive promotion. A donor that changes history or authority to generate its effect is rejected. A donor that duplicates baseline behavior without a measurable gain is rejected as redundant. A donor whose result depends on a language model remains blocked until a frozen model-facing benchmark exists.

Promotion is always two-stage: Bride qualification first, then a separate Frankenstein integration patch followed by the same qualification against the integrated implementation.

Evidence tiers:

1. Harness self-test. Synthetic evaluator only. No donor claim.
2. Frozen Frankenstein deterministic qualification.
3. Longitudinal deterministic qualification with restarts, delayed probes, and held-out cases.
4. Renderer substitution using a fixed subject state and evidence surface.
5. Model-dependent mechanism qualification when the mechanism requires a real model.
6. Blinded human or independent adversarial evaluation for claims about recognizability or human-likeness.

A lower tier must never be described as a higher one.
